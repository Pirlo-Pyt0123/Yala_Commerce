## 🍸 Tu Licor Favorito, a un Solo Click

**YALA Licorería** es una propuesta visual y conceptual de comercio electrónico premium, diseñada minuciosamente para revolucionar la experiencia de adquirir bebidas y licores de forma online. 

Combinando una estética **Dark Minimalist** con acentos neón muy vibrantes y efectos visuales de última tendencia, el proyecto destaca por su enfoque en la interfaz de usuario (UI) y la experiencia fluida del cliente (UX).

##  Características Clave de la Interfaz

*   **🎨 Paleta Dark & Neón:** Uso estratégico de fondos oscuros profundos combinados con verdes brillantes (`#22c55e`) para simular el ambiente de eventos y vida nocturna.
*   **🧪 Estilo Moderno:** Implementación limpia de componentes visuales avanzados como *Glassmorphism* y texturas orgánicas abstractas.
*   **🛍️ UX Intuitiva:** Menú de navegación minimalista con accesos rápidos a carrito, estado de pedidos, contacto y panel de administración en la barra superior.
*   **💬 Widget de Asistencia:** Botón flotante de chat interactivo integrado para soporte en tiempo real.
